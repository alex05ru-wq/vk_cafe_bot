# Чат-бот кофейни ВКонтакте

Бот для сообщества ВКонтакте на официальном API (Long Poll), без конструкторов.

## Возможности
- Меню кнопками по категориям, добавление позиций в корзину
- Корзина с подсчётом суммы, очистка
- Ответы на частые вопросы: адрес и часы, оплата, акции
- Предзаказ: с собой / в зале, время готовности, комментарий, подтверждение
- Заказ приходит администратору с кнопками «Готовится» и «Готов» — клиент сразу получает уведомление
- Меню, цены и ответы — в `config.py`, код менять не нужно

## Настройка сообщества
1. Управление → Сообщения: включить сообщения сообщества и «Возможности ботов»
2. Управление → Работа с API → Ключи доступа: создать ключ (доступ к управлению сообществом и сообщениям)
3. Работа с API → Long Poll API: включить; в типах событий отметить «Входящее сообщение» и «Действие с сообщением»

## Запуск
1. `pip install -r requirements.txt`
2. Скопируйте `.env.example` в `.env` и заполните
3. Напишите сообществу любое сообщение со страницы администратора
4. `python bot.py`

Технологии: Python, vk_api (VK Bot Long Poll API)
